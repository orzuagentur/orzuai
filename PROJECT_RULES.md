# PROJECT_RULES.md

## Project Name

OrzuAI

## Mission

Create the easiest AI WhatsApp Assistant platform for small businesses.

---

## Tech Stack

Frontend:

* Next.js 15
* TypeScript
* Tailwind CSS
* Shadcn UI

Backend:

* Supabase

Database:

* PostgreSQL

AI:

* Gemini

Email:

* Resend

Hosting:

* Vercel

---

## Design Rules

* Minimalistic UI
* Modern SaaS design
* White background
* Purple primary color
* Rounded corners
* Consistent spacing

---

## Development Rules

* Always use TypeScript
* No any types
* Clean code only
* Reusable components
* Mobile responsive
* Production ready code

---

## Folder Naming

Use:

* kebab-case for folders
* PascalCase for components

Examples:

components/AuthCard.tsx

components/DashboardCard.tsx

---

## Security Rules

* Never expose API keys
* Use environment variables
* Use Supabase RLS
* Validate all inputs

---

## AI Rules

Before creating code:

1. Read ARCHITECTURE.md
2. Read TASKS.md
3. Check completed tasks
4. Continue from last unfinished task

Never modify completed modules without approval.
